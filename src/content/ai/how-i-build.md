title: How I build with AI
order: 0
problem:
  text: I work full-time as a product manager. At the same time I'm looking for a remote PM role, keeping a portfolio current, writing, running a side label and keeping my money in order. Each of these is a stream of small, repetitive tasks, like tailoring a resume, checking a number, updating a page or reading the day's email. None of them is hard. Together they don't fit in the hours left after work.
  pending: true
principles:
  - text: Most of the work is routing, not thinking. Finding a job, pulling evidence for a case study and updating a site are separate jobs. Each needs its own context and rules. One general assistant would have to relearn all of them every time.
    pending: true
  - text: Specialists beat generalists when the inputs differ. A job-search assistant needs listings and application forms. A writing assistant needs my work email, Notion and resumes. A site builder needs the repository. Splitting by area keeps each one focused.
    pending: true
  - text: Handoffs are where quality leaks. If one assistant's output is the next one's input, the contract between them matters more than any single prompt.
    pending: true
  - text: Trust depends on not making things up. A portfolio with one invented number is worse than one with a gap.
    pending: true
system:
  - text: I organise my assistants into areas.
  - text: "Professional. A job-search assistant finds remote PM roles and applies to them. A writing assistant handles my resume, portfolio case studies and articles. A site-builder assistant builds and maintains this portfolio site. It opened the GitHub pull request for v1."
  - text: Financial. A private assistant tracks money.
  - text: Daily. A personalised newspaper assistant pulls from my email and calendar every day.
  - text: Meta. A bot-designer assistant creates new assistants when a new area needs one.
  - text: "The assistants hand work to each other. For this site, the writing assistant sourced my case studies from my work email and Notion, then passed them to the site builder to lay out. The writing assistant has one hard rule: if it can't verify a number, it flags it instead of inventing one."

  - text: Tighten the handoffs so each assistant states what it checked and what it couldn't.
    pending: true

    pending: true
outcome:

  - text: Every metric is either traced to a source or marked as unverified, so I know exactly what I still need to confirm before anything goes public.
  - text: The morning briefing and job search run in the background while I do my actual job.
